❌ Failure of Parametric Baselines

3-Sigma Shewhart & EWMA assume Gaussian normality. On non-Gaussian IoT streams (Weibull/Gamma sensor noise), they generate up to 48.99% false alarm rate and coverage collapses to ~51%.

💥 Memory Explosion of Full-History

Full-History Bootstrap requires accumulating all past observations. On MetroPT-3 ($N=1.51M$), memory explodes to ~90.9 MB causing Out-Of-Memory (OOM) on edge IoT devices. RBULT-SPC stays bounded at 0.70 KB.

⚡ Amortized O(1) Streaming Latency

Boundary expansion is triggered only when chunk min/max values exceed existing limits. Steady-state streaming amortizes computational cost to < 10 ms per 1,000 samples.
